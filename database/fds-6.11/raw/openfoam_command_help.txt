<command_begin>
<command>
fds <chid>.fds
</command>
<help_text>
Run FDS on one mesh in the current directory. Writes <chid>.out (progress, warnings, ERROR lines), <chid>.smv, <chid>_devc.csv, <chid>_hrr.csv and slice/boundary files. Source FDS6VARS.sh first.
</help_text>
</command_end>
<command_begin>
<command>
mpiexec -n <N> fds <chid>.fds
</command>
<help_text>
Run FDS with N MPI processes; N must equal the number of &MESH records (or a divisor with MPI_PROCESS assignments). Set OMP_NUM_THREADS=1 for pure MPI runs.
</help_text>
</command_end>
<command_begin>
<command>
fds <chid>.fds with &TIME T_END=0 /
</command>
<help_text>
Setup-only run: reads the input, builds meshes and obstructions, writes <chid>.smv and stops. Use it as a fast syntax and geometry check before a real run.
</help_text>
</command_end>
<command_begin>
<command>
smokeview -runscript <chid>
</command>
<help_text>
Run Smokeview unattended with the script <chid>.ssf (RENDERDIR, LOADSLICE <label> <dir> <coord>, SETTIMEVAL, RENDERONCE, UNLOADALL). Headless: xvfb-run -a -s '-screen 0 1280x800x24' smokeview -runscript <chid>. Slice labels come from <chid>.smv, e.g. 'SOOT VISIBILITY', 'TEMPERATURE'.
</help_text>
</command_end>

<command>
fds2ascii
</command>

</help_text>
</command_end>
